# Instructions for AI assistants

Before doing anything else, read `PROGRESS.md` — it has current status,
what's done, what's blocked, and next steps. Don't ask the user to
re-explain project history; it's in that file.

Before ending a session (or after any meaningful change), update
`PROGRESS.md` to reflect the new state: what changed, what's still
pending, and any new blockers.
